# Sales Forecasting

## Objective

The objective of this task was to predict future revenue using historical sales data and machine learning techniques.

## Tools Used

- Python
- Jupyter Notebook
- Pandas
- Scikit-Learn
- Matplotlib

## Machine Learning Model

### Linear Regression

Linear Regression was used to identify revenue trends and forecast future sales performance.

## Methodology

### Data Preparation

- Converted transaction dates into monthly periods.
- Aggregated monthly revenue.

### Feature Engineering

- Created a numerical month index.

### Model Training

- Split data into training and testing datasets.
- Trained the Linear Regression model.

### Model Evaluation

Performance was evaluated using:

- R² Score
- Mean Absolute Error (MAE)

### Revenue Prediction

Predicted revenue for future periods based on historical trends.

## Results

The model successfully identified sales patterns and generated future revenue forecasts.

- Inventory Planning

- Resource Allocation
- Strategic Decision-Making

## Outcome

Developed a machine learning model capable of forecasting future revenue trends and supporting business planning activities.
